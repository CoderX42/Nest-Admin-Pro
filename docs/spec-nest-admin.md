   5. 认证与授权规范                                                                                      
                                                                                                          
   JWT 载荷                                                                                               
                                                                                                          
   ```ts                                                                                                  
     interface IAuthUser {                                                                                
       uid: number   // 用户 ID                                                                           
       pv: number    // 密码版本                                                                          
       exp?: number                                                                                       
       iat?: number                                                                                       
       roles?: string[]                                                                                   
     }                                                                                                    
   ```                                                                                                    
                                                                                                          
   权限装饰器                                                                                             
                                                                                                          
   ```ts                                                                                                  
     @Perm('system:user:list')   // 定义并校验权限                                                        
     @AllowAnon()                // 登录即可，不校验权限                                                  
     @Public()                   // 完全公开                                                              
   ```                                                                                                    
                                                                                                          
   守卫执行链（全局注册）                                                                                 
                                                                                                          
   1. JwtAuthGuard：JWT 校验、token 黑名单、密码版本、单设备、Demo 模式写保护                             
   2. RbacGuard：按 @Perm() 校验权限，admin 角色 bypass                                                   
   3. ThrottlerGuard：全局限流（默认 60 秒 20 次）                                                        
   4. ResourceGuard（按需）：校验数据归属权                                                               
                                                                                                          
   6. DTO 与校验规范                                                                                      
                                                                                                          
   公共 DTO                                                                                               
                                                                                                          
   ┌────────────────────────────┬────────────────────────────────────┐                                    
   │ DTO                        │ 作用                               │                                    
   ├────────────────────────────┼────────────────────────────────────┤                                    
   │ PagerDto                   │ 分页：page、pageSize、field、order │                                    
   ├────────────────────────────┼────────────────────────────────────┤                                    
   │ CursorDto                  │ 游标分页                           │                                    
   ├────────────────────────────┼────────────────────────────────────┤                                    
   │ IdDto                      │ 单 ID                              │                                    
   ├────────────────────────────┼────────────────────────────────────┤                                    
   │ DeleteDto / BatchDeleteDto │ 删除/批量删除                      │                                    
   ├────────────────────────────┼────────────────────────────────────┤                                    
   │ OperatorDto                │ createBy / updateBy                │                                    
   └────────────────────────────┴────────────────────────────────────┘                                    
                                                                                                          
   查询 DTO 标准写法                                                                                      
                                                                                                          
   ```ts                                                                                                  
     export class UserQueryDto extends IntersectionType(                                                  
       PagerDto,                                                                                          
       PartialType(UserDto),                                                                              
     ) {}                                                                                                 
   ```                                                                                                    
                                                                                                          
   创建/更新 DTO                                                                                          
                                                                                                          
   • Create DTO：完整字段 + 校验规则                                                                      
   • Update DTO：通常 PartialType(CreateDto)                                                              
                                                                                                          
   常用校验装饰器                                                                                         
                                                                                                          
   @IsString、@IsInt、@IsEmail、@IsMobilePhone、@IsArray、@ArrayNotEmpty、@MinLength、@MaxLength、@Matches
   、@IsIn、@IsBoolean、@Validate(IsUnique) 等。                                                          
                                                                                                          
   7. Controller 路由与 Swagger 规范                                                                      
                                                                                                          
   标准 CRUD 路由                                                                                         
                                                                                                          
   ```ts                                                                                                  
     @Get()           list(@Query() dto: QueryDto)                                                        
     @Get(':id')      read(@IdParam() id: number)                                                         
     @Post()          create(@Body(CreatorPipe) dto: CreateDto)                                           
     @Put(':id')      update(@IdParam() id, @Body(UpdaterPipe) dto: UpdateDto)                            
     @Delete(':id')   delete(@IdParam() id)                                                               
   ```                                                                                                    
                                                                                                          
   Swagger 装饰器                                                                                         
                                                                                                          
   ┌────────────────────────────────────────────┬───────────────────┐                                     
   │ 装饰器                                     │ 作用              │                                     
   ├────────────────────────────────────────────┼───────────────────┤                                     
   │ @ApiTags('Group - 模块名')                 │ 控制器分组        │                                     
   ├────────────────────────────────────────────┼───────────────────┤                                     
   │ @ApiOperation({ summary: '...' })          │ 接口说明          │                                     
   ├────────────────────────────────────────────┼───────────────────┤                                     
   │ @ApiSecurityAuth()                         │ Bearer Token 鉴权 │                                     
   ├────────────────────────────────────────────┼───────────────────┤                                     
   │ @ApiResult({ type: Entity, isPage: true }) │ 统一响应结构      │                                     
   ├────────────────────────────────────────────┼───────────────────┤                                     
   │ @ApiConsumes('multipart/form-data')        │ 文件上传          │                                     
   └────────────────────────────────────────────┴───────────────────┘                                     
                                                                                                          
   8. 响应封装规范                                                                                        
                                                                                                          
   • TransformInterceptor 全局包装响应为：                                                                
                                                                                                          
   ```json                                                                                                
     {                                                                                                    
       "code": 0,                                                                                         
       "data": ...,                                                                                       
       "message": "success"                                                                               
     }                                                                                                    
   ```                                                                                                    
                                                                                                          
   • @Bypass() 可跳过该包装                                                                               
   • 分页数据使用 Pagination 对象，结构为 { items, meta }                                                 
                                                                                                          
   9. 异常处理规范                                                                                        
                                                                                                          
   • BusinessException：业务异常，HTTP 状态码 200，错误码在 body 中                                       
   • ErrorEnum 集中管理错误码，格式 "code:message"                                                        
   • AllExceptionsFilter：全局兜底，生产环境隐藏内部错误                                                  
   • 全局 ValidationPipe：自动转换 + 白名单过滤，校验失败返回 422
